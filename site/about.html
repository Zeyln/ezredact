About Nyktios

Nyktios is a free image editor for covering or pixelating parts of a screenshot or photo. It works on phones and computers, with no account.

How your images are handled

  • Images are opened and edited in your browser. They are not uploaded.
  • The site has no backend, analytics or cookies, and loads nothing from other websites.
  • The open image and your edits are cleared when you close the page or switch away from it.
  • Saved images are new PNG files without metadata such as location or camera details.

Finding text (beta)

The optional Find text button looks for text in your image so you can cover it in one step. It needs a download of about 56 MB, and asks before starting. The download comes from this site and contains a text detection model (CRAFT) and ONNX Runtime Web, which run on your device. Your image is not uploaded. It can miss text, especially small text in photos, so check the image before sharing it. See the third-party notices.

Hosting

The site is hosted on GitHub Pages. GitHub logs visitors' IP addresses for security purposes. See the GitHub Pages documentation.

Limits

  • Your phone or browser may keep its own traces, such as app-switcher previews or download history.
  • Use solid boxes for text. Pixelated text can sometimes be reconstructed.
  • Nyktios is an early test version, so check saved images before sharing them.

Source and contact

The source code is public. Report problems or ask questions through GitHub Issues.
